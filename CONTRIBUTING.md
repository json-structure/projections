(https://www.ietf.org/).

You agree to comply with all applicable IETF policies and procedures, including
BCP 78, BCP 79, the TLP, and the TLP rules regarding code components in
Contributions.

## How to Contribute

Open an [issue](https://github.com/json-structure/projections/issues) or a
[pull request](https://github.com/json-structure/projections/pulls).

For mapping changes, identify the affected source and target types, the
governing specifications, and the effect on value preservation, native
constraint enforcement, and model reconstruction. Include boundary examples
for any claim that a projection is lossless.

Edit the Markdown draft source. Generated text, XML, and HTML files are
build outputs and are not maintained as source.
